# Shared style (one source for every task)

Edit the block below: the station puts it in front of every prompt, so all pictures share one look.

## Prompt block

```
STYLE: detailed hand-drawn pixel art in high resolution for a 2D side-scroller, crisp clean pixels, a clear dark
outline, believable materials, muted palette with one warm accent for human light and cold teal/violet for alien
things. Pure flat side view. Do NOT paint glow, bloom or halos: emissive parts are painted flat, the game adds glow
from a separate mask. Flat solid magenta #FF00FF background.
```
